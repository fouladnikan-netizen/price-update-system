## تصمیم قطعی

1. هیچ‌یک از ۶ مقدار `sku` تکراری ادغام نمی‌شود.
2. هر دو لوله با ضخامت متفاوت باید `sku` یکتای جدا داشته باشند.
3. هر ورق فابریک و هر ورق پرسی باید `sku` یکتای جدا داشته باشد.
4. سامانه قیمت مجاز به ساخت `sku` یا `product_code` جدید نیست.
5. اصلاح فقط در Website انجام می‌شود.

تا اصلاح Website، این ۱۲ ردیف برای Import سامانه قیمت قابل پذیرش نیستند.
